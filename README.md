1. Install Node.js and npm
Ensure that Node.js and npm (Node Package Manager) are installed on your computer.
Download and install from Node.js official website.
Verify the installation by running the following commands in your terminal:
bash
# code
'node -v'
'npm -v'
3. Install Vite
Vite is a fast and efficient build tool that works well with React.
Open your terminal and run the following command to install Vite:
bash
# Code
'npm create vite@latest'
Follow the prompts:
Enter your project name.
Select "React" when asked for a framework.
Choose  "TypeScript".
4. Navigate to Your Project Directory
After the project setup is complete, navigate to the project directory:
bash
# Code
'cd your-project-name'
5. Install Dependencies
Install the necessary dependencies by running:

# Copy code
'npm install'
6. Download my git hub files and folders in your system after that you have to delete the all files in your new created projects files and folders except
'node_modules'.
now you have to past my code in your new created project. now you can run your server. 
7. Start the Development Server
To start the Vite development server and run your React app, use:

# Copy code
npm run dev
Open your browser and navigate to the URL provided (usually http://localhost:5173).
8. Open the Project in Your Code Editor
Open your project in your preferred code editor, such as VS Code, to start building your React app.
